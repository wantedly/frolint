# @wantedly/prettier-config-wantedly

> [!NOTE]
> This package is published to [GitHub Packages](https://github.com/wantedly/frolint/pkgs/npm/prettier-config-wantedly) only (not npm) as `@wantedly/prettier-config-wantedly`.
> Add the following line to `.npmrc` in your project, and authenticate to GitHub Packages with a token that has the `read:packages` scope.
>
> ```
> @wantedly:registry=https://npm.pkg.github.com
> ```

Prettier configuration for Wantedly.

## Usage

Install `@wantedly/prettier-config-wantedly`.

```
$ yarn add -D @wantedly/prettier-config-wantedly
or
$ npm install --save-dev @wantedly/prettier-config-wantedly
```

And then, you use it in Prettier configraiton.

```
"@wantedly/prettier-config-wantedly"
```
